ak:diagram — connector effects

Eight zero-dependency SVG connector effects. All render with only tokens.css and connector-effects.css loaded. Apply via data-fx="<name>" on any path.

marching-ants

Dashed stroke slides along the path.

comet

Bright segment traverses the path with a trailing fade.

wave

Stroke width breathes with a sine wave.

morse

Dot–dash pattern travels the path.

glow

Drop-shadow pulses without moving the stroke.

silhouette

Small shape rides the path via offset-path.

pulse

Stroke width + opacity breathe together.

dashed-flow

Slow ambient dash-drift for background structure.
